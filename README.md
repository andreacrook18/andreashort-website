# Andrea Short - Professional Portfolio Website

A clean, professional personal website featuring three pages: Home, CV, and Teaching Philosophy.

## Pages

- **Home** (index.html): Welcome page with profile picture and introduction
- **CV** (cv.html): Complete curriculum vitae with education, positions, certifications, and accomplishments
- **Teaching Philosophy** (teaching-philosophy.html): Teaching philosophy statement

## Files

- `index.html` - Home page
- `cv.html` - CV page
- `teaching-philosophy.html` - Teaching philosophy page
- `styles.css` - Stylesheet for all pages
- `profile.jpg` - Profile picture (add your image with this name)

## Setup Instructions

1. Clone this repository
2. Add your profile picture named `profile.jpg` to the repository root
3. Open `index.html` in your browser to view the site
4. To deploy on GitHub Pages:
   - Go to your repository Settings
   - Scroll to "GitHub Pages" section
   - Select the branch to deploy (e.g., main or website-setup)
   - Your site will be available at `https://andreacrook18.github.io/andreashort-website/`

## Features

- Responsive design that works on desktop and mobile devices
- Clean, professional styling
- Easy navigation between pages
- Contact information displayed on home page

## Customization

- Edit the content directly in the HTML files
- Modify colors by changing the hex values in `styles.css`
- Update navigation links if you change page names
